# 视频倍速控制 · Video Speed Controller

用快捷键控制**任意网页视频**的播放速度。支持跨域 iframe 嵌入的视频、预览视频、动态加载的播放器，并带「强制保持」功能——当网站偷偷把速度改回 1.0 时自动复位到你设定的倍速。

## 安装（开发者模式加载）

1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本文件夹
4. 安装后，**刷新**你要使用的视频页面（已经打开的旧标签页需要刷新一次内容脚本才会注入）

## 默认快捷键

| 按键 | 功能 |
| --- | --- |
| `D` | 加速（+步长，默认 2） |
| `S` | 减速（−步长） |
| `Z` | 恢复 1.0x |
| `A` | 一键倍速（在 1.0x 与设定倍速如 4.0x 之间切换） |
| `R` | 快退（默认 5 秒） |
| `X` | 快进（默认 5 秒） |
| `V` | 常驻 / 隐藏左上角速度提示 |

> 在输入框、文本域里打字时快捷键自动失效，不会误触；输入法组字过程中也不拦截。
> 但播放器用 `<input type="range">` 做的进度条 / 音量条**不算**打字，快捷键照常生效。
> 按住 Ctrl/⌘/Alt 时不拦截。

## 弹窗（点工具栏图标）

- 直接点预设按钮或用 `+ / −` 设速度
- 修改步长、一键倍速目标、快进秒数
- 「记住上次速度」：新视频自动套用上次速度
- 「按域名自动静音」：在指定域名（默认含 `115vod.com`）上，视频自动静音并强制保持
- 自定义快捷键：点对应输入框后按一下你想要的键
- **导出 / 导入配置**：备份设置，或搬到其他浏览器（如 Edge）

## 三个容易踩的坑，以及扩展是怎么绕过去的

### 1. Chrome 原生控件的「键盘黑洞」

Chrome 自带的 `<video controls>` 控件条整个活在 UA shadow DOM 里。焦点一旦落进去（点了进度条、播放键、音量、全屏按钮），这条控件会把键盘和鼠标事件**全部吞在内部**——页面上连 `window` 捕获阶段都收不到任何 `keydown`。表现就是：**在播放的视频上点一下进度条，倍速快捷键从此彻底失灵。**

页面唯一能收到的信号，是焦点第一次进入时那一个 `focusin`（target 被重定向成 `<video>` 本身）；而「先点画面、再点进度条」这条最常见的路径，因为页面看到的 `activeElement` 前后都是同一个 `<video>`，**连 `focusin` 都不会再发一次**。

所以扩展在发现媒体元素的 frame 里开一个 120ms 的轮询：只要 `document.activeElement` 是 `<video>`/`<audio>`，就重新 `focus()` 一次宿主元素，把焦点从控件条内部拽回来。键盘事件立刻恢复，而且 `<video>` 依然是焦点元素，空格/方向键这些原生快捷键也还在。焦点没有真正变化时 `focus()` 不派发任何事件，因此不会和站点的焦点管理打架，也不影响拖动进度条。

### 2. 按键只送到「有焦点」的那个 frame

键盘事件只会送到当前有焦点的 frame。焦点如果在别的 iframe（广告位、评论框、播放器外壳）里，按键就全丢了——鼠标明明指着视频也没用。

现在的路由：本 frame 先立刻响应，然后把指令**上送到顶层**，由顶层再向整棵 frame 树广播下去。每条指令带唯一 id，收到重复 id 只转发不重复执行（否则快进会跳两步）。

### 3. `<video>` 自己全屏时提示看不见

全屏状态下页面其余内容根本不参与渲染，挂在 `body` 上的提示会被全屏层整个盖掉。提示改用 popover（top layer）渲染，并在 `fullscreenchange` 时重新入栈，所以全屏时也看得见；顺带也不再怕站点祖先元素上的 `transform` / `filter` / `overflow` 把 `position:fixed` 圈住。

## 和页面里其它脚本共存（手动优先）

用户一旦亲手调过速度，扩展会在媒体元素上打一个 `data-vsc-user="<倍速>"` 属性。这个属性写在共享 DOM 上，页面里的油猴脚本读得到——自动变速类脚本看到它就该让位。配套的《视频增强合集》脚本 4.7.1 起已经按这个约定实现：

- 你按下倍速热键，或扩展打了 `data-vsc-user`，或速度被改成「既不是脚本目标、也不是 1」的值 → 脚本本页永久撒手，连之后新出现的预览也不再自动变速。
- 反过来，扩展只在目标速度非 1.0 时才持续强制；按「复位」到 1.0 之后有 10 秒的强制窗口，之后就交还给站点，不会长期跟站点自带的倍速菜单打架。

## 按域名自动静音

在弹窗「参数」里打开「按域名自动静音」，并在「自动静音域名」框里每行填一个域名（支持子域，如 `115vod.com` 也匹配 `www.115vod.com`）。命中的页面里所有视频会被自动静音；若站点或播放器又取消静音，扩展会强制把它重新静音。

视频常嵌在跨域 iframe 内，扩展除了判断当前 frame 域名，还会用 `location.ancestorOrigins` 检查祖先 frame，所以即便播放器在子 iframe 里也能命中。

## 配置同步与备份

- **跨设备同步**：配置存在 `chrome.storage.sync`，登录同一 Google 账号并开启 Chrome 同步后，多台电脑的设置自动共享。未登录时它退化为本机存储，照常可用。
- **导出/导入**：弹窗底部「导出配置」生成 `video-speed-config.json`；在另一台机器或另一个浏览器点「导入配置」选择该文件即可。
- 「记住的上次速度」属于设备本地状态（存 `local`、按键时防抖写入），不参与同步，避免触发 sync 的写入频率配额。

## 已知限制

- **closed shadow DOM 里的 `<video>` 发现不了**。媒体事件不是 composed 的，跨不出 shadow 边界；`mode:'closed'` 的 shadow root 又拿不到 `shadowRoot` 引用。要覆盖只能在 MAIN world 里改写 `attachShadow`，代价是可能弄坏依赖封装的站点，所以没做。开放式（open）shadow DOM 是支持的。

```

content.js      核心:媒体发现 / 倍速 / 强制保持 / 快捷键 / frame 路由 / 焦点黑洞修复
content.css     速度提示样式(含 popover 的 UA 默认样式覆盖)
popup.html/.css/.js   工具栏弹窗 UI 与设置
icons/          扩展图标
```
